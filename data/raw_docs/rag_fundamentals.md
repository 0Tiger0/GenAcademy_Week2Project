# Retrieval Augmented Generation (RAG)

## What is RAG?

Retrieval Augmented Generation (RAG) is an AI architecture that combines information retrieval with large language models.

Instead of relying solely on model training data, RAG retrieves relevant information from external documents and provides that context to the language model before generating an answer.

## Why Use RAG?

RAG helps organizations:

- Reduce hallucinations
- Use current information
- Ground responses in trusted documents
- Improve transparency through citations
- Avoid expensive model retraining

## Core Components

A RAG system typically contains:

1. Documents
2. Chunking
3. Embeddings
4. Vector Database
5. Retrieval
6. Large Language Model
7. Response Generation

## Typical Workflow

User Question
↓
Retrieve Relevant Chunks
↓
Provide Context to LLM
↓
Generate Grounded Answer

## Enterprise Use Cases

- Internal knowledge assistants
- Policy question answering
- Customer support systems
- Document search
- AI governance assistants

## Advisor Notes

Organizations should consider RAG when they need answers grounded in company documentation or frequently changing information.
