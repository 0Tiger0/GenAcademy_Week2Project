# Claude Overview

Claude is Anthropic's AI assistant designed for reasoning, writing, analysis, and coding tasks.

## Strengths

Claude is often useful for long-form analysis, document review, coding assistance, brainstorming, and structured writing.

## Enterprise Use Cases

- Summarizing large documents
- Drafting professional content
- Reviewing code
- Analyzing requirements
- Assisting with technical planning

## Safety Approach

Anthropic emphasizes AI safety, helpfulness, harmlessness, and alignment.

## Advisor Notes

Claude is a strong fit when users need thoughtful writing, code assistance, and long-context document reasoning.
