# Custom GPTs

## What are Custom GPTs?

Custom GPTs allow organizations and users to create specialized AI assistants tailored for specific business needs.

## Capabilities

Custom GPTs can:

- Follow custom instructions
- Use uploaded knowledge
- Support specific workflows
- Provide domain-specific guidance

## Enterprise Use Cases

- IT support assistant
- HR policy assistant
- Finance knowledge assistant
- AI governance advisor
- Project management assistant

## Governance

Organizations should review:

- Data sources
- User access
- Security controls
- Usage monitoring

## Advisor Notes

Custom GPTs are useful when organizations need specialized AI experiences without building a custom application from scratch.
