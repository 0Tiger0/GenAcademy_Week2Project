# Microsoft Copilot Security

## Overview

Microsoft Copilot is designed to work within the Microsoft 365 security, compliance, and identity ecosystem.

## Identity and Access

Copilot uses existing Microsoft 365 permissions and identity controls. Users should only receive responses based on content they already have permission to access.

## Data Protection

Organizations should review data access, sharing permissions, sensitivity labels, retention policies, and compliance settings before broadly deploying Copilot.

## Governance Considerations

Important governance steps include:

- Reviewing SharePoint and OneDrive permissions
- Applying sensitivity labels
- Managing user access
- Auditing Copilot usage
- Training users on responsible AI use

## Enterprise Use Cases

Copilot is suitable for organizations that already use Microsoft 365 and want AI assistance while maintaining existing security and compliance controls.

## Advisor Notes

Before deploying Copilot widely, organizations should clean up over-permissioned content and confirm that governance controls are in place.
