# ChatGPT Enterprise Overview

## What is ChatGPT Enterprise?

ChatGPT Enterprise is OpenAI's enterprise-grade AI platform designed for organizations.

Key features include:

- Unlimited higher-speed GPT access
- Enterprise-grade security
- Data privacy protections
- Admin controls
- Advanced analytics
- Custom GPTs

## Security

OpenAI does not train models on enterprise customer data.

Data is encrypted in transit and at rest.

## Use Cases

- Knowledge management
- Document summarization
- Coding assistance
- Research
- Enterprise search

## Benefits

Organizations can improve productivity while maintaining security and governance controls.
