# Microsoft Copilot Overview

Microsoft Copilot is an AI assistant integrated into Microsoft products and services.

## Microsoft 365 Integration

Copilot works across Microsoft 365 apps such as Word, Excel, PowerPoint, Outlook, Teams, and SharePoint.

## Strengths

Copilot is useful when an organization already uses Microsoft 365 and wants AI assistance inside existing productivity workflows.

## Common Use Cases

- Summarizing Teams meetings
- Drafting emails
- Creating documents
- Analyzing spreadsheets
- Searching organizational content

## Advisor Notes

Copilot is usually the best fit when users need AI inside Microsoft 365 applications and enterprise data already lives in Microsoft services.
